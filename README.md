# Book Covers

**把一本书的余韵，留在一幅画里。**

[在线画廊](https://zjuzhiyucai.github.io/book-covers/) · [English](README.en.md) · [安装与使用](#安装与使用) · [发布记录](https://github.com/ZJUZhiyuCai/book-covers/releases)

![Book Covers — 文学封面、提示词与可复用 Skill](press/github-cover.png)

Book Covers 是一组开放的文学封面作品，也是一套可独立安装的 Agent Skill。先生成无字插画，再用真实字体为书名与作者排版，让画面和题字各有表达，也彼此呼应。

当前使用 **Skill 1.4.0**，两辑共收录 **20 幅生成插画、40 张中英文封面**。暖白纸面、少量墨色和疏朗的构图，构成这一系列的视觉语言。你可以在画廊浏览、下载作品，也可以把 Skill 交给自己的 Agent，为其他书籍设计封面。

## 你会得到什么

| 输出       | 内容                                                 |
| ---------- | ---------------------------------------------------- |
| 无字 PNG   | 完整保留选定的生成插画                               |
| 带字 PNG   | 在插画上用真实字体排入书名与作者，文字由排版程序合成 |
| 生图提示词 | 完整的可复制文本，同时提供 UTF-8 TXT 文件            |

只做一种语言时，共交付三个文件；同时做中英文时，共用原图与提示词，分别输出带字封面，共四个文件。画廊中每本书的页面都有下载和复制入口。排版配置、WebP 预览和来源记录可按需另存。

## 安装与使用

把下面这段话发给 Codex 或其他支持 Skills 的 Agent：

```text
请安装 Book Covers skill：
https://github.com/ZJUZhiyuCai/book-covers/tree/main/skills/book-covers
使用你原生的技能安装方式，包含 references 和 runtime；如已安装，保留本地修改后更新。
完成后告诉我调用方式。
```

Codex 可使用内置的 `skill-installer`。无需手动下载 ZIP 或克隆整个画廊。安装后，按 Agent 的提示刷新技能列表，即可尝试：

```text
使用 $book-covers 为路遥的《平凡的世界》设计中文封面。
请交付无字 PNG、使用真实字体排版的带字 PNG，以及可复制的生图提示词。
```

其他兼容 Agent 也可通过 [Skills CLI](https://github.com/vercel-labs/skills) 安装：

```sh
npx skills add ZJUZhiyuCai/book-covers --skill book-covers
```

### 使用前需要什么

- **生图能力**：由宿主 Agent 提供。Skill 包含创作规范、参考样张与排版工具，不附带图像模型或 API 额度。
- **本地执行能力**：排版工具需要 Node.js 22+ 和 npm，依赖由 Agent 准备。
- **字体文件**：工具会按需下载固定版本的开源字体并校验，不必安装系统字体，也不用手动寻找文件。依赖与本次所需的字体准备好后，可离线排版。

详见 [安装说明](INSTALL.md) 与 [排版工具用法](skills/book-covers/references/runtime.md)。

## 画面与题字

每张封面从一个空间关系出发：一条小路通向黄土坡上的窑洞，一匹白马走过广阔的沙丘。少量形体承担故事的情绪，留白为题字和读者留下余地。

简约服务于故事。判断一张封面时，要同时看它的场景感、尺度关系和题字，而不只数画面里剩下多少元素。轻微的纸面质感可以保留，抢过主体的纹理则需要取舍；一组封面也应放在一起看，避免仅靠换色和换道具制造差别。

中文书名主要使用朱雀仿宋；《白马啸西风》选用 Ma Shan Zheng 的毛笔字形。一个中文主标题中的字保持等大、等重，节奏来自字距、断行与轴线。英文采用 Cormorant Garamond 正体和独立设计的斜体，按短语的含义安排层级。

《红楼梦》的竖排、《边城》的疏朗短题、《到灯塔去》的正斜体搭配，以及《白马啸西风》的笔势，展示了同一系列里不同的题字方式。

## 实测结果与当前边界

2026 年 10 月 16 日，用未修改的 Skill 1.4.0 制作了第二辑十部作品。Agent 逐书拟定构图和排版，再审阅生成结果。这是一次有选择、有修正的实际制作记录。

| 检查               | 本轮结果                                               |
| ------------------ | ------------------------------------------------------ |
| 插画生成           | 10 次新生成，另对《围城》做了 1 次删减编辑             |
| 中英文排版         | 20 张首轮导出成功，未修改初始排版方案                  |
| 同环境重复导出     | 固定原图、字体和配置，40 个交付文件的 SHA-256 全部一致 |
| Skill 与画廊一致性 | 20 张带字 PNG、10 份提示词内容一致                     |

**目前较可靠的是文字排版与文件交付，画面仍需逐张判断。** 部分作品存在纹理偏密、构图相近或留白位置不够准确的问题；《城南旧事》和《百年孤独》在记录中保留了这些意见。当前画廊保留这轮选定的版本，便于对照实测结果。

相同原图上的重复排版，不等于再次生图会得到相同画面。这十个案例也不能代表所有书籍、图像模型或运行环境的成功率。实际提示词、返工过程、校验值和复跑配置均见[完整观察记录](docs/stability/vol-02/README.md)。

## 本地运行与导出

如需修改画廊或直接使用命令行排版，克隆仓库后在根目录运行：

```sh
npm ci
npm run dev                 # 本地预览：http://127.0.0.1:4187/
npm test                    # 检查书目、排版、文件保护与本地服务
npm run build               # 生成画廊、封面与提示词下载文件
npm run export              # 七张竖版作品图与横版介绍图 → output/
npm run compose -- --spec examples/complete-cover.json --out output/custom
```

开发服务启动时构建一次；修改后执行 `npm run build` 并刷新浏览器。`PORT=4190 npm run dev` 可换端口。画廊依赖准备完成后，构建与导出不联网。

要为其他书籍排版，复制 [示例配置](examples/complete-cover.json)，填写书名、作者、断行，以及相对于该 JSON 文件的插画和提示词路径。默认输出上述三类文件；`--webp` 可增加 640 × 960 预览图，`--receipt audit.json` 可保存校验值和字体来源。已有输出默认受保护；`--force` 可替换输出，但仍会拒绝覆盖输入文件。

源图为 **1024 × 1536 像素**，适合屏幕展示。放大导出不会增加插画细节；实体印刷所需的开本、出血、书脊和色彩打样尚未包含在内。

## 项目结构与贡献

欢迎带来新的书籍与设计思路。[贡献指南](CONTRIBUTING.md)说明了如何保留实际提示词、源图与修正记录。每件新作都应找到自己的文学空间。

```text
skills/book-covers/  可独立安装的 Skill、参考图与排版工具
catalog.json        中英文书目、设计意图、排版方案与源图校验值
artwork/            原始生成插画
prompts/            实际生成与修正提示词
process/            历史修正、实验输入与证据
src/                静态页面模板、样式与交互
scripts/            构建、排版、导出与本地预览
press/              可分享的作品汇总图
fonts/              字体文件、来源与 OFL 许可
tests/              内容、排版、文件保护与服务检查
```

画廊使用静态 HTML/CSS 和少量 JavaScript，没有分析追踪或在线生图后端。画廊与 Skill 共用排版核心：`fontkit` 提取字形轮廓，`sharp` 合成 PNG，并检查文字实际边界是否越界或重叠。`subset-font` 制作界面所需的 WOFF2 字体子集；GitHub Actions 负责测试、构建和发布。
