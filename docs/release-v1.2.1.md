# Book Covers v1.2.1

The project is now **Book Covers**. The reusable skill is named `book-covers` and is invoked as `$book-covers`.

- Repository: https://github.com/ZJUZhiyuCai/book-covers
- Gallery: https://zjuzhiyucai.github.io/book-covers/
- The gallery, documentation, installer, complete-cover imprint, promotional sheets and release packages use the new name.
- The literary art direction, bilingual typography and complete-cover workflow are unchanged. Source illustrations remain intact.

If you installed `quiet-book-covers`, move your old skill folder outside the agent's skill directory before installing `book-covers`; keep any personal edits as a backup. Earlier releases retain their original names and files.
