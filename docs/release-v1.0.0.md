# Quiet Covers v1.0.0 · Stories & space

The first public collection brings together ten literary interpretations, a reusable visual skill, and a bilingual gallery.

- Ten original text-free illustrations; twenty Chinese/English typeset PNG covers.
- Full generation prompts, design briefs, source checksums and two documented margin revisions.
- An independently installable `quiet-book-covers` skill, with four visual references.
- A static gallery with individual work pages, category filters, artwork/cover comparison and downloads.
- Deterministic title and author layout, reusable export commands, tests and GitHub Pages deployment.
- Four vertical press sheets, a wide project banner and Chinese launch-copy drafts.

Code, prompts and skill instructions: MIT. Original generated artwork: CC BY 4.0 to the extent rights can be licensed. Font: OFL 1.1. These are independent design studies, not publisher editions.

## Downloads

- `quiet-book-covers-v1.0.0.zip`: the skill folder, references and licenses.
