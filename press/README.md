# 展示素材

这些文件是可直接选用的展示素材，不会自动发布到任何平台。

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `01-introduction.png` | 1440 × 1920 | 六张精选，适合作为小红书首图 |
| `02-chinese-literature.png` | 1440 × 1920 | 五部中国文学作品 |
| `03-world-literature.png` | 1440 × 1920 | 五部外国文学作品 |
| `04-process.png` | 1440 × 1920 | 插画、文字、成品的拆解 |
| `05-typography.png` | 1440 × 1920 | v1.0 与 v1.1 的中英文文字设计对照 |
| `github-cover.png` | 1800 × 900 | GitHub README 或项目介绍 |

建议顺序：首图 → 中国文学 → 外国文学 → 过程拆解 → 字体对照。封面中的空白是构图的一部分，分享时保留整张竖幅。

`npm run export` 可重新生成同一组排版，输出到 `output/`。它合成已保存的插画与字形，不会重新调用生图工具。文案草稿见 [launch-copy.zh.md](launch-copy.zh.md)，可按自己的口吻修改。
